# Default theme with an extensible token contract

`@tirox-ui/preset` จะมี default theme ที่ใช้งานได้ทันที พร้อมเปิด Token Contract ให้ผู้ใช้ replace หรือ extend ได้ โดย recipes จะอ้างอิง semantic tokens และ CSS variables เป็น boundary ของ runtime theme การตัดสินใจนี้รองรับ brand themes และ color modes โดยไม่ทำให้ component behavior ผูกกับค่าการออกแบบชุดใดชุดหนึ่ง
