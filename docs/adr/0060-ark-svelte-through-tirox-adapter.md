# Ark UI Svelte through a Tirox adapter

เมื่อเริ่มรองรับ Svelte, `@tirox-ui/svelte` จะใช้ Ark UI Svelte เป็น behavioral foundation ผ่าน Tirox Svelte adapter เช่นเดียวกับ Solid adapter โดยรักษา shared semantic contracts และ behavior test vectors แต่ใช้ Svelte-native reactivity, slots, refs และ events ไม่ fork logic ใหม่โดยไม่จำเป็น
