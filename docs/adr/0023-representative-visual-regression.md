# Representative visual regression with a theme matrix

Tirox UI จะมี visual regression tests สำหรับ component และ states ที่เป็นตัวแทน ร่วมกับ theme matrix ที่ครอบคลุม default/custom theme, light/dark, responsive และ reduced-motion states โดยไม่ snapshot ทุก DOM node เพื่อควบคุม noise และ maintenance cost
