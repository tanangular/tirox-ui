# Radix-inspired default color scales

default preset ของ Tirox UI จะใช้ Radix-inspired 12-step color scales เป็น primitive color foundation แต่ custom preset ไม่ถูกบังคับให้ใช้จำนวนหรือชื่อขั้นเดียวกัน โดยต้อง map ค่าเข้าสู่ semantic token contract ให้ครบ เพื่อรักษาทั้ง visual consistency และ design-system portability
