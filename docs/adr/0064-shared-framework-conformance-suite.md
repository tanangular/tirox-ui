# Shared framework conformance suite

ทุก framework adapter ต้องผ่าน shared conformance suite ที่ตรวจ semantic behavior, states, accessibility expectations และ component scenarios เดียวกัน พร้อม adapter-specific tests สำหรับ reactivity, refs, lifecycle และ native events ของ frameworkนั้น Solid และ Svelte ต้องผ่าน foundation component matrix ก่อน stable release และ snapshot เพียงอย่างเดียวไม่ถือเป็น parity evidence
