# Slot recipes with modern CSS styling

Tirox UI จะเปิด styling ผ่าน slot recipes, typed variants และ explicit state selectors โดยพยายามใช้ความสามารถของ modern CSS แทนการพึ่ง DOM selector ภายในหรือ override แบบไม่เป็นสัญญา แนวทางนี้ทำให้ anatomy และ customization surface อ่านได้ชัด และยังคงแยก behavior ออกจาก presentation
