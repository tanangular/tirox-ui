# Measured performance budgets

Tirox จะ benchmark foundation components ทั้ง 6 ตัวก่อน แล้วใช้ข้อมูลจริงกำหนดทั้ง absolute budgets และ regression budgets สำหรับ bundle size, generated CSS, SSR/hydration cost, interaction latency และ docs Core Web Vitals การเลือกตัวเลขแบบ arbitrary หรือวัดเฉพาะ docs ไม่เพียงพอสำหรับ framework contract
