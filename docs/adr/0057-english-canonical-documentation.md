# English as canonical documentation language

documentation ของ Tirox UI จะใช้ภาษาอังกฤษเป็น canonical language สำหรับ API, types, code examples และ concepts เพื่อให้ตรงกับ ecosystem ของ SolidJS, Panda CSS และ Park UI ส่วนภาษาไทยจะเพิ่มเป็น translation/support layer ภายหลัง โดยไม่สร้าง terminology ที่เป็น canonical ซ้ำสองชุด
