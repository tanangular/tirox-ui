# Reusable preset conformance suite

Tirox UI จะมี reusable preset conformance suite ที่ default และ custom presets ใช้ร่วมกัน เพื่อตรวจ required semantic tokens, slot/variant contracts, semantic contrast และ Panda input compilation มาตรฐานเดียวกันนี้ทำให้ custom Design System เปลี่ยนค่าได้โดยไม่ทำให้ framework contract ขาดหาย
