# Evergreen browser baseline

Tirox UI จะรองรับ evergreen browsers รุ่นล่าสุดและรุ่นก่อนหน้า 1 major version เป็น baseline กลางของ packages และ documentation การกำหนด baseline นี้เปิดให้ใช้ modern CSS อย่างเหมาะสมและลด compatibility burden ที่ไม่จำเป็น โดยฟีเจอร์ที่ support จำกัดยังต้องมี fallback หรือไม่เป็นส่วนหนึ่งของ public contract
