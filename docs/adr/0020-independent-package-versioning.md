# Independent package versioning with shared compatibility policy

`@tirox-ui/solid` และ `@tirox-ui/preset` จะใช้ independent versioning และ release ได้แยกกัน แต่ต้องมี shared compatibility policy และ compatibility matrix ใน documentation การเปลี่ยนเฉพาะ behavior/API ของ framework หรือเฉพาะ token/recipe contract จึงไม่บังคับให้ package อีกตัวต้อง release ตามโดยไม่มีเหตุผล
