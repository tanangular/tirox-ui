# Primitive and semantic token layers

`@tirox-ui/preset` จะมีทั้ง primitive token scales และ semantic tokens โดย recipes ต้องอ้างอิง semantic tokens เป็นหลัก การแยกสองชั้นทำให้ custom theme เปลี่ยน mapping หรือ brand values ได้โดยไม่ต้องแก้ component recipes และยังเปิดทางให้ renderer mappings ใช้ semantics เดียวกัน
