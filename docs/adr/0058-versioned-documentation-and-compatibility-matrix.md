# Versioned documentation with an explicit compatibility matrix

Astro documentation จะ version ตาม release ที่มี public API change และระบุ versions ของ `@tirox-ui/solid` กับ `@tirox-ui/preset` ที่ examples ใช้ พร้อม compatibility matrix เนื่องจาก packages ใช้ independent versioning current docs จะ consume workspace versions ปัจจุบัน ส่วน historical docs ต้องคงข้อมูลตาม release เดิม
