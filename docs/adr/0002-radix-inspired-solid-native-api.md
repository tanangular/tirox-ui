# Radix-inspired, Solid-native API

Tirox UI จะรักษาความหมายของ component, anatomy, props, variants และ composition ให้คุ้นเคยกับ Radix UI แต่ใช้ types, events และ reactive conventions ของ SolidJS 2.0 โดยไม่รับประกันการนำโค้ด React มาใช้แบบ drop-in การเลือก semantic compatibility ลดการฝืน React API และทำให้ framework ใช้งานได้เป็นธรรมชาติบน SolidJS
