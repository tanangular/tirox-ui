# WAI-ARIA APG and WCAG 2.2 AA contract

ทุก component ของ Tirox UI จะมี accessibility contract ตาม WAI-ARIA Authoring Practices Guide และ WCAG 2.2 ระดับ AA โดยต้องตรวจสอบ semantics, keyboard navigation, focus management, state communication และ color contrast ใน component และ documentation examples การมี Ark UI เป็น behavioral foundation ไม่ได้ยกเว้น Tirox จากการตรวจสอบ contract ของตนเอง
