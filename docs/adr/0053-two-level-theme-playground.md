# Two-level theme playground

Astro documentation จะมี runtime theme playground ผ่าน root-scoped CSS variables เพื่อการทดลองทันที และ compile-time custom preset example เพื่อแสดงการ replace/extend tokens กับ Panda inputs/config จริง การแยกสองระดับทำให้ผู้ใช้เข้าใจทั้ง runtime switching และ consumer-owned CSS generation
