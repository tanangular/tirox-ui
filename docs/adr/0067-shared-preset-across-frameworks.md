# Shared framework-neutral preset across Solid and Svelte

`@tirox-ui/preset` จะเป็น package เดียวที่ใช้ร่วมกันทั้ง `@tirox-ui/solid` และ `@tirox-ui/svelte` เพราะ tokens, recipes, Panda inputs และ Design System contract ไม่ควรผูกกับ framework การแยกตาม framework จำกัดเฉพาะ adapter, markup, behavior binding และ native conventions
