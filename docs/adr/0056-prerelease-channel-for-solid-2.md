# Separate prerelease channel for SolidJS 2.0 compatibility

ระหว่างที่ SolidJS 2.0 ยังเป็น prerelease, Tirox จะเผยแพร่ packages ผ่าน prerelease channel แยก พร้อม peer range, compatibility matrix และ changelog ที่ชัดเจน breaking changes ใน prerelease ต้องประกาศ แต่ stable semver contract จะเริ่มเมื่อ Tirox ประกาศ stable support อย่างเป็นทางการ
