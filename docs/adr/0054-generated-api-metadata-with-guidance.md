# Generated API metadata with authored guidance

Astro docs จะ generate metadata ของ props, events, slots และ exported types จาก TypeScript source จริง และให้ผู้ดูแลเขียน behavior, accessibility, edge-case และ recipe guidance ประกอบ CI ต้องตรวจความสอดคล้องระหว่าง generated metadata กับ explicit package exports เพื่อป้องกัน documentation drift
