# Shared token categories

`@tirox-ui/preset` จะกำหนด shared token contract อย่างน้อยในกลุ่ม color, typography, spacing/sizing, radius, shadows, motion และ z-index/layers เพื่อให้ recipes, DOM/SVG styling และ future renderer mappings ใช้ vocabulary เดียวกัน พร้อมเปิดให้ custom preset replace หรือ extend ค่าได้
