# Component acceptance contract

component ใหม่ของ Tirox UI จะถือว่าเสร็จเมื่อมีครบทั้ง behavior และ edge-case tests, controlled/uncontrolled กับ keyboard/focus tests, การตรวจ WAI-ARIA APG + WCAG 2.2 AA, slot recipe และ typed variants, executable Astro example และ API/type กับ source recipe documentation เกณฑ์เดียวนี้ทำให้ behavior, styling, accessibility และ learning surface เดินไปพร้อมกัน
