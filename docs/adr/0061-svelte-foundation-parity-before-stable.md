# Svelte foundation parity before stable release

`@tirox-ui/svelte` จะออก stable release ได้เมื่อมี parity ครบทั้ง Button, Input, Checkbox, Select, Dialog และ Tooltip และแต่ละ component ผ่าน core acceptance contract พร้อม Svelte-specific checks การมี prerelease adapter บางส่วนทำได้ แต่ต้องประกาศว่าเป็น prerelease และห้ามสื่อว่าเทียบเท่า Solid แล้ว
