# Package-first distribution with open source recipes

โครงการเลือกแจกจ่าย UI Framework ผ่าน package เป็นหลัก พร้อมเปิดเผย source และ recipe ให้ผู้ใช้ปรับแต่งและดูแลต่อได้ การตัดสินใจนี้รักษาความสะดวกของ package ecosystem ไว้พร้อมความยืดหยุ่นด้าน Design System และสอดคล้องกับแนวคิด open code ของ Park UI; ทางเลือกแบบ package-only จำกัดการปรับแต่ง ส่วน source-only เพิ่มภาระเริ่มต้นให้ผู้ใช้
