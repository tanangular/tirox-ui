# Solid-native controlled and uncontrolled state API

Tirox components จะรองรับทั้ง uncontrolled mode สำหรับการใช้งานทั่วไปและ controlled mode สำหรับการควบคุมจากภายนอก โดยใช้ SolidJS-native reactive API และ callback conventions การตัดสินใจนี้รักษาความยืดหยุ่นที่ผู้ใช้คาดหวังจาก Radix โดยไม่ผูก component กับ React state model
