# Typed native props and events

Tirox components จะรองรับ native HTML/SVG attributes และ event handlers ตาม rendered element แบบมี type safety และเพิ่ม Tirox-specific props เฉพาะ behavior ที่จำเป็น โดยต้องไม่กลืนหรือเปลี่ยน native semantics โดยไม่จำเป็น และต้องกำหนด precedence เมื่อ Tirox จัดการ prop เดียวกัน
