# Migration guide: pre-1.0 to 1.0

This guide is a release template and becomes normative when v1 is published.

## Required review

Before upgrading, run `pnpm check`, `pnpm test`, `pnpm test:e2e`, `pnpm security:check`, and `pnpm contract:check`. Confirm the package and preset versions in [`docs/compatibility.md`](../compatibility.md).

## API policy

Public component exports are only the explicit package exports. Internal source paths are unsupported. Breaking changes to props, slots, semantic `data-*` states, controlled/uncontrolled behavior, IDs, or portal containers require a migration note and a Changeset.

## Security policy

Do not treat `disabled`, visibility, or rendered content as authorization. Keep consumer-sanitized content behind the branded API and keep hydration payloads allowlisted and secret-free.
